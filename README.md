# Company-Performance-Analysis-PowerBI

## Overview
This project focuses on analyzing company performance using Power BI to track key business metrics, sales trends, customer performance, and operational insights.  
The dashboard provides an interactive and data-driven view of company performance to support strategic business decision-making.

The goal of this project is to transform raw business data into meaningful insights through visualization, KPI tracking, and performance analysis.

---

# Tools & Technologies Used
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

---

# Project Objectives
- Analyze overall company performance
- Track sales and revenue trends
- Identify top-performing products and customers
- Monitor KPIs and business growth
- Generate actionable business insights

---

The dataset includes:
- Sales data

- Product details
- Revenue and profit metrics
- Regional and category performance
